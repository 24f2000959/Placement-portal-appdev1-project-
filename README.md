#  Placement Portal

A web-based **Placement Portal** designed to simplify and manage the campus placement process for students, recruiters, and administrators.

The application provides a centralized platform where students can view available placement opportunities and apply for jobs, while administrators can manage students, companies, job postings, and applications.

---

##  Features

### Student

- Student registration and login
- Manage student profile
- View available job opportunities
- View company details
- Check job eligibility
- Apply for jobs
- View applied jobs
- Track application status

### Company / Recruiter

- Company registration and login
- Manage company profile
- Create job postings
- Specify job requirements and eligibility criteria
- View applications
- Review student details
- Manage recruitment process

###  Admin

- Admin authentication
- Manage students
- Manage companies
- Manage job postings
- Manage applications
- Monitor placement activities
- View placement-related information
